# Aurelia Restaurant Website

A premium, modern, responsive website for Aurelia Fine Dining.

## Overview
A fictional fine-dining restaurant website designed to deliver an elegant and luxurious online experience.

## Features
- Responsive design for desktop and mobile
- Elegant restaurant landing page
- Menu showcase
- Restaurant information
- Reservation enquiry section
- Premium visual styling

## Technologies
- React
- TypeScript
- Tailwind CSS
- Vite

## Development
Built in Lovable and synced with GitHub.

## Status
Demo project — not affiliated with a real restaurant.
